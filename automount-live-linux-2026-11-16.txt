A defect found by this measurement (fixed in go-freedesktop/gvfs v0.1.1, PR 2)
-------------------------------------------------------------------------------
The first run used the default XDG_RUNTIME_DIR, where the desktop session's gvfsd-fuse already owns /run/user/1000/gvfs: the private session's gvfs-fuse could not mount (fusermount3: failed to access mountpoint, Permission denied), ListMounts2 returned an empty FusePath and a DefaultLocation of "/" (the root inside the mount), and gvfs v0.1.0 returned "/" as the path: the host's root directory. gvfs v0.1.1 returns the URI in that case. With gvfs v0.1.1 and the default XDG_RUNTIME_DIR the output is:
